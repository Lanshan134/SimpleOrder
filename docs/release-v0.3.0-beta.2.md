# 简序 · SimpleOrder v0.3.0-beta.2

本次 beta 小版本整合智能快速录入及中文数字支持，并包含之前已进入 beta 的日期编辑修复。仍为试用版本，main 保持不变。

## 新增：智能录入

- 管理器任务名称框输入 `交报告 明天 18:00`，回车拆分并填入名称、日期和时间，仍需点击保存。
- 悬浮列表、悬浮日历和管理器左侧快速添加框会蓝色标记识别片段，回车或 + 创建。
- 支持今天、明天、后天、三天后、本周/下周/最近星期、明确及无年份日期。
- 支持 `下午三点开会`、`三点半开会`、`十五点二十分`、`十一月二十五日` 和中文年份；“两”和零分也可识别。
- 手工字段冲突、非法日期时间、多个日期时间或缺少名称时保留输入；取消确认也不清空文本。计划名称不解析。
- 离线解析，不调用外部服务。具体规则见仓库 docs/smart-entry.md。

## 日期编辑修复

- 普通点日期进入新建占位表单，输入名称后才锁定创建；保存后解除锁定。
- 已有任务先点入日期框，再点日历才能改期；其他日期点击仅在实际改动时询问保存。
- 修复一次日历点击被重复处理，支持同日切回新建，取消后恢复日期选择。

## 下载与运行

下载 `SimpleOrder-v0.3.0-beta.2-Windows-x64.zip`，完整解压后运行 `SimpleOrder.exe`。保留 DLL、插件、样式和许可文件，无需另装 Qt。GitHub 的 Source code 附件为源码，不能直接运行。

升级前先退出旧程序，继续沿用 `%LOCALAPPDATA%/LightTaskLocal/LightTask/` 数据目录。详情需保存才写入数据库；升级前建议导出一份备份。

## 当前边界

- “今晚”及新的跨日推断暂不支持；未识别的词保留在名称中。可用今天/明天明确日期。
- 今天/明天彩色日期标签仅为需求 #7，本次尚未实现。
- 图标上栏、日历展开及尚未合并的界面文案清理不包含在本包中。
- 时间仅记录，不发送通知；暂不支持跨设备同步。

Windows x64 / Qt 5.15.2 / MinGW 8.1 构建并执行隔离自检。源码采用 MIT，随包提供第三方许可说明。
