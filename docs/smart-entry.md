# 智能快速录入

## 使用

- 在管理器的任务名称框中输入 `交报告 明天 18:00`，按回车填入名称、日期和时间。回车不保存，仍需点击保存。
- 悬浮列表、悬浮日历和管理器左侧的快速添加框会在输入时以蓝色标记日期/时间片段，悬停查看解析结果；回车或 + 创建任务。
- 计划名称不参与解析，避免改变重复计划的规则。
- 所有识别离线完成，不发送任何文本到外部服务。

## 支持的表达

| 类别 | 示例 | 约定 |
|---|---|---|
| 相对日期 | 今天、明天、后天、3天后 | 按录入时本机日期计算 |
| 星期 | 本周五、下周一、周一、星期一 | 本周和下周按周一开始；无前缀取今天或之后最近一次 |
| 明确日期 | 2026-11-05、2026/11/5、2026年11月5日 | 有年份时保持指定日期 |
| 无年份日期 | 11月5日、11/5 | 取今天或之后最近有效日期；2/29 可落到下个闰年 |
| 时间 | 18:00、18：00、下午3点、晚上8点半、8点20分 | 未写时段按24小时理解；下午/晚上1–11点加12，凌晨/晚上12点为0点 |

日期、时间可位于名称前后，也支持 `明天下午3点 开会`。普通数字如 `学习第3章`、`项目2026` 不拆分。

## 默认日期与冲突

- 纯名称快速添加仍然不安排日期，也不安排时间。
- 只有时间：列表快速添加默认今天；悬浮日历快速添加用选中日期；管理器名称表单保留已有日期，空日期使用当前选中日期。
- 新建表单自动带入的日期可被解析结果替换；手工日期或已有任务的非空日期，与解析结果冲突时不覆盖。时间框已有不同时间时也不覆盖。
- 冲突时保持所有原文和字段，可先清空对应字段再按回车解析。
- 多个日期/时间、无效日期/时间或缺少名称时不创建，不清空输入；错误在悬停提示中展示。
- 快速添加因未保存表单确认而取消时，原快速输入继续保留。

此功能使用明确规则，不是通用自然语言理解。未支持的表达留在名称中；创建前可根据蓝色标记与悬停结果检查识别范围。

## 中文数字

同时支持 `下午三点`、`三点半`、`十五点二十分`、`三天后`、`十一月二十五日`、`二〇二八年二月二十九日`，以及“两”和前导零（如“两点零五分”）。高亮仍使用原文位置，不把任务名称里的普通中文数字全局替换。

本次只增加中文数字，不引入“今晚”及新的跨日推断。未识别的“今晚”等词保留在名称中；请用已有的“今天/明天”表达明确日期。
