# 简序 · SimpleOrder 编辑区域设计

顶部采用任务 / 计划页签；计划按规则显示独立配置区域。

- 任务：名称、类型、可选日期与时间、备注、置顶。移除开始/截止时间选择。
- 周期次数：每天 / 每周 / 每月，目标次数，可选有效期与时间；按自然周期独立计数。
- 指定日期：按周多选星期，或按月多选日期及月末；每个执行日独立完成。
- 间隔重复：每 N 天，固定日期或完成后顺延，首次日期必填，可选结束日期与时间。
- 累计目标：统一目标次数，不提供单位选项；不按周期归零，可选有效期，不显示执行时间。
- 计划共同字段：名称、类型、备注、置顶；日历选项根据规则调整。

上述四种规则已实现到当前源码、SQLite 存储、JSON 备份以及日历执行日显示。

## 操作说明

- 顶部页签切换任务和计划。任务支持不安排日期；计划的可选日期和时间可清空。
- 完成通过列表方框操作，编辑表单不再提供完成、开始/截止时间选择。
- 周期次数使用自然日、周一开始的自然周、自然月。列表显示当前周期进度；日期详情操作对应选中日期。
- 指定日期每个执行日独立完成；月末规则支持跳过或补到最后一天。
- 间隔重复：固定日期按首次日期计算；完成后顺延则在完成指定天数后再次出现，逾期保持待办。
- 累计目标统一次数，没有单位选项；日历可标记结束日期。
- 更改规则或目标后使用新配置计数，旧规则计数继续存放在备份记录中。当前尚未提供历史计数浏览界面。
- 原有计划首次编辑按累计目标载入并保留原进度。数据库首次升级前自动生成 `.before-plan-*.bak`。
- 独立编辑窗口支持保存、放弃和关闭；关闭时保留当前草稿，不弹保存询问。
悬浮窗右键编辑使用独立编辑窗口，不唤起管理窗口。

## 紧凑布局与滚轮

- 原新建/编辑事项标题位置改为靠左书签“任务 / 计划”，保留未保存草稿。页签和保存栏均固定在表单滚动区域外。
- 类型与规则、周期与次数、间隔与计算方式、开始与结束日期成对排列；窄窗口自动换成单列。
- 备注默认两行高。规则摘要合并为一条，详细解释可悬停查看。
- 表单滚轮只控制外层纵向滚动。聚焦的次数、下拉选择及其弹层、备注和书签都不会响应滚轮修改或切换；键盘及点击操作正常。

## 草稿与透明度

- 新计划不继承日历选中日期作为结束日期，默认无限期。
- 点击日历日期时，当前任务的日期直接更新到草稿；计划的有效期不随日历选择变化。
- 打开其他窗口、关闭独立编辑窗口、浏览日历均保留本次运行中的草稿，不自动提交数据库。
- 进入另一事项时，只有当前可保存内容确实变化才询问保存；重复点击当前事项、聚焦控件和恢复原值不会触发提示。
- 设置 > 悬浮窗 > 外观提供“窗口背景不透明度”和“文字不透明度”，分别独立保存，均支持 0–100%。管理窗口不受影响。
