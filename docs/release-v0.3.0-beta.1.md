# 简序 · SimpleOrder v0.3.0-beta.1

首个 GitHub 试用版，基于 beta 分支发布。功能与数据结构仍可能调整。

## 下载与运行

下载 `SimpleOrder-v0.3.0-beta.1-Windows-x64.zip`，完整解压到可写目录后运行 `SimpleOrder.exe`。不要只取出 EXE；请保留同目录 DLL、插件、样式和许可文件。不需要另装 Qt。

GitHub 自动提供的 Source code 为源码包，不能直接运行。

## 主要功能

- 桌面悬浮任务列表与月历，可置顶、缩放，背景和文字透明度独立设置。
- 任务与计划独立编辑，支持自然日/周/月次数、指定日期、间隔重复与累计次数目标。
- 自定义类型及彩色标记，完成事项淡化、删除线和历史保留。
- 日历改期、非模态编辑、草稿暂存与实际改动确认。
- SQLite 本地存储、JSON 导入导出及自动备份。

## 升级与边界

- 请先退出旧版。继续使用原数据目录 `%LOCALAPPDATA%/LightTaskLocal/LightTask/`；数据库升级前会自动备份，升级前也建议在设置中导出一份备份。
- 草稿暂存限于本次运行，详情需要点击保存。时间字段仅作记录，不发送通知。尚不支持跨设备同步。
- 更改计划规则或目标会按新配置计数，旧计数仍存放在备份记录中，尚无独立历史计数浏览页。
- 已在 Windows / Qt 5.15.2 / MinGW 8.1 x64 环境构建并运行自动自检；不同 DPI、多屏及真实桌面交互仍需用户试用反馈。
